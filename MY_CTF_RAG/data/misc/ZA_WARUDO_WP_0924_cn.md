## 解题过程

本题是一场两阶段作战：**阶段一「找不同」**（定位原曲 + 锁定注入频段），**阶段二「信号分离与解码」**（复数域抵消 + 同步头破译）。卡点恰好发生在一二阶段的交界处——也正是本题最值得复盘的地方。

### 第零步：梗即路标 —— 咋瓦鲁多 = 时停

「砸瓦鲁多」= ZA WARUDO，JOJO 里 DIO 的时停名台词；题干「时间会告诉我们答案的」双关点题。顺着 B 站线索找到原曲出处：**Stranded In Space**（B站 avid `435860352`，红警2·心灵终结 Music Omega 系列）——它正是**悖论引擎（Paradox Engine）**的关联 BGM，而悖论引擎的招牌技能恰是「时间静止」。主题完全闭环，但也埋了第一个坑：**很容易先入为主往「变速/倒放/时间拉伸」方向猜**。

### 第一步：B站缓存取证 —— 从本地缓存挖出原曲

不需要重新下载：B站 PC 客户端的缓存就在本地，结构规整：

```
C:\Users\<user>\Videos\bilibili\435860352\
├── videoInfo.json              ← 视频元信息（标题确认 Stranded In Space）
├── 435860352-1-30280.m4s       ← 音轨（30280 = B站音频流 ID）
└── 435860352-1-30016.m4s       ← 视频轨
```

m4s 只是头部带了一小段垃圾字节的音视频流，找到 `ftyp` 盒子砍掉前缀即是标准 m4a：

```python
data = open('435860352-1-30280.m4s','rb').read()
i = data.find(b'ftyp')            # 本例 i = 13
open('orig.m4a','wb').write(data[i-4:])
```

转 48kHz PCM 后待用（`orig.wav`，3'33.85"）。与题目 `challenge.flac`（3'33.48"）时长几乎一致——第一直觉「变速」基本可以存疑了，但需要硬证据。

### 第二步：排除时间轴篡改 —— 「时间」没有说谎

用低频音乐主体（100–3000 Hz 带通）做互相关对齐：**前、中、后三个位置测得的偏移完全一致（4055 samples ≈ 84.5 ms，恒定）**。若存在变速，偏移会线性漂移；若存在拼接/删除，分段偏移会跳变。都没有——时间轴干净，唯一差异是恒定 84.5 ms 的整体错位。

> 倒放（`reversed.flac`）、FLAC 内嵌封面图（`cover.png` 旋转/放大）也排查过，均无果。排除法到此，「不同」只能在频域里。

### 第三步：找不同 —— 锁定 4.4–7.6 kHz 注入频段（阶段一终点）

逐拍（beat ≈ 1.6678 s）FFT 对比两份音频：低频主体几乎逐 bin 一致，但**高频段冒出一批原曲没有的窄带音调**，候选集中在 4.4–7.6 kHz：

```
候选注入音调（8 个）：4719, 4907, 5040, 5491, 6047, 6199, 7003, 7200 Hz
```

同时摸清了整体结构——这份数据后来被证明是半程最有价值的产出：

- **Phase 1（t ≈ 0.3–53.4 s）**：稀疏，组起点**严格每 3.3333 s 一个，共 16 组**
- **Phase 2（t ≥ 53.4 s 至尾）**：密集数据段，8 个候选频率都有动静

### 第四步：卡点与破局 —— 幅度域的坑，复数域的解

**卡点复盘**：用「题目包络 > 5×底噪中位数 且 > 3×原曲包络」的双条件在 8 个候选频率上抓「题目有、原曲无」的事件，结果 Phase 1 的事件分布是——

```
6199 Hz × 7 次    7003 Hz × 24 次    7200 Hz × 7 次
```

**真同步头应该是两个频率各 8 次规整出现**——最吵的 7003（24 次随机扎堆）其实是 AAC↔FLAC 编码器差异的伪影。幅度域里「编码器伪影」与「注入信号」不可分：`orig` 是 AAC 317kbps 解码、`challenge` 是 FLAC，两条链路的量化噪声、相位偏移在幅度对比里全长得像信号。

**破局**：换到**复数域做频点抵消**。对每个候选频点 `f`，用 100 ms Hann 窗、5 ms hop 计算滑窗复数 DFT 系数，分别得到题目的 `C_f(k)` 与对齐后原曲的 `O_f(k)`；由于两条编码链路存在固定的幅相差，估计一个**复传递系数** `H_f`：

```
C_f(k) ≈ H_f · O_f(k)        H_f = ⟨O, C⟩ / ⟨O, O⟩
残差 R_f(k) = |C_f(k) − H_f · O_f(k)|
```

为避免真正的隐藏脉冲污染拟合，每轮只保留残差最小的 65% 帧、迭代 8 轮。本题解出 `H_6199 ≈ 0.917+0.169j`、`H_7200 ≈ 0.885+0.189j`——音乐本体在残差里被大幅压低，而 6199/7200 Hz 上 50–60 ms 的短脉冲干净现身。**8 个候选里只有这 2 个在残差中存活，其余 6 个就此出局。**

### 第五步：0xAA55 同步头 —— 同步头白送映射表

Phase 1（t < 53 s）在两个存活频点上只检出 16 个脉冲（每 3.333 s 一个），按时间排成：

```
7200 6199 7200 6199 7200 6199 7200 6199 | 6199 7200 6199 7200 6199 7200 6199 7200
```

令 `6199 Hz = 0`、`7200 Hz = 1`：

```
10101010 01010101  =  0xAA 0x55
```

`0xAA55`——数字通信里最经典的帧同步字（ alternating 方便时钟恢复，AA55 对便于字节对齐校验）。同步头不仅标定了数据段起点，还**直接送出了频率→bit 的映射表**，无需任何猜测。

### 第六步：200 bit → 25 字节 → flag

Phase 2（t ≥ 53 s，首脉冲 53.660 s，末脉冲 168.275 s）用同样方法抓到**恰好 200 个数据脉冲**（200 = 8 × 25，干净的倍数本身就是解对的信号），按时间排序转 bit，MSB-first 每 8 位一个字节：

```
01101110 01110000 01110101 01110011 01100101  →  n p u s e c
01100011 01111011 ...                          →  c { ...
```

```text
npusec{wHat3v3r_1t_t4kes}
```

`Whatever it takes`——复联梗收尾，flag 长度 25 字符 = 25 字节，与脉冲数严丝合缝。

## 知识点沉淀

1. **B站缓存取证**：`Videos\bilibili\<avid>\` 下 `<avid>-1-30280.m4s` 是音轨；m4s = 垃圾头 + 标准 fMP4，`find(b'ftyp')` 前砍即 m4a。不必重新找资源下载
2. **变速检测**：分段互相关看偏移——恒定=干净、线性漂移=变速、跳变=拼接。「时间会告诉我们答案」这类题面先做时间轴体检再谈别的
3. **复数频点抵消**：跨编码（AAC vs FLAC）对比的正确姿势——样本级对齐 + 每频点复 DFT + 迭代拟合复传递系数 H + 残差检测。幅度域对比必被编码器伪影污染
4. **0xAA55 同步头**：通信协议经典帧头（alternating 便于时钟恢复）。规整的稀疏脉冲段优先当同步头解——它同时解决「数据从哪开始」和「频率怎么映射」两个问题
5. **BFSK**：两个单音分别代表 0/1 是最朴素也最常见的音频数字调制；检测 = 频点能量/残差脉冲流 → 按时间排序 → 转 bit
6. **自洽性验证**：200 脉冲 = 8×25 字节、flag 长度 25 字符、前缀 `npusec{` 与 `}` 闭合——解码正确性不需要外部确认，结构自己会说话

## 方法论反思：音频对比题以后怎么打（本次最大收获）

这题前半程很顺（定位原曲→排除变速→锁定注入频段），**卡死在「候选信号真伪」这一步**——检测出 8 个候选频率，直接锚定「8 bit 并行字节流」假设，在网格拟合/码字字典上狂奔了很久。复盘后沉淀为音频 diff 题的标准作业程序：

1. **先对齐，再对比**——样本级互相关拿到精确 shift，是一切 diff 的前提
2. **跨编码对比必须复数域**——幅度域里编码器伪影与注入信号不可分；一个复系数 H 吸收全部幅相差，残差里只剩真信号
3. **候选信号先验「规整度」再进编码推断**——真信号时间规整（等间隔、事件数干净），伪影随机扎堆。逐候选单独数事件分布，30 秒就能把 8 个候选杀到 2 个
4. **规整稀疏段 = 同步头优先**——不要在组内间隔里找编码规律（那常常是伪影之间的间隔，等于在噪声里找模式）；同步头（AA55/55AA 等）会白送映射表
5. **最朴素解释优先**——「N 个候选频率 ≠ N bit 并行」，2-FSK 串行流远比 8-bit 和弦常见；符号宽度是假设不是事实，先验证再精化

一句话：**检测器的输出是「嫌疑犯」不是「罪犯」，进入解码推断前先过规整度验证这一关。**

## 踩坑记录

- **时停梗是烟雾弹**：题目叙事（咋瓦鲁多/时间静止）把注意力往变速、倒放上引，实际时间轴完全干净——梗用于确认原曲身份（悖论引擎），不是手法提示
- **幅度域 diff 的假阳性**：AAC↔FLAC 编码差异在 6 个频点上制造了稳定的「题目有原曲无」假象（7003 Hz 假事件 24 次 vs 真信号各 8 次）；双阈值（底噪×5 + 原曲包络×3）仍不够，唯一可靠解是复数域抵消
- **伪影间隔不是编码**：Phase 1 组内间隔呈现 {a, b, a+b, a+2b} 的「规律」，花了很多时间找节奏编码——事后看那是假阳性事件之间的间隔，纯粹的噪声模式
