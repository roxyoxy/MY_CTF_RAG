1：Crypto-solve 
知识点：多元线性丢番图方程 
题目难度：中等  
建议分值：200 分 
题目说明：解方程 
提交flag 格式：flag{xxxx}。 
Flag：flag{d1b6d42cd11049738d7170c3e83f956b} 
解题过程： 
分析代码我们可以得知列表 a 中的数据(除最后一项)分别与一个特殊列表 x 的每一项相乘
后 会得到 a 的最后一项，于是有下列表达式： 
a0*x0 + a1*x1 +… +an-1*xn-1 = an  
我们知道 a 的所有数据求 x 的所有项 
这就是多元线性丢番图方程，而由题目可以得知该方程必有解且解为 x，而多元线性丢番图 
方程有解当且仅当 gcd(a0,a1,…,an)整除 an，可知这里一定满足该条件。 
我们首先考虑二元线性丢番图方程的解，假设有 ax+by=c,（这次 gcd(a,b)整除 c），我们考
虑 x,y 的一个特解 
我们可以通过扩展欧几里得算法来计算出表达式 ax+by=gcd(a,b)的 x,y 值，这里记为 xg,yg 
那么我们很容易可以推导得出 ax+by=c 的解，x=xg*(c/gcd(a,b)) y=yg*(c/gcd(a,b)) 
然后我们再回到多元线性丢番图方程，根据方程表达式，我们可以有下列推导： 
d0 = gcd(a0,a1)  
d1 = gcd(d0,a2)  
… …  
dn-2 = gcd(dn-3,an-1)  
a0*x0 + a1*x1 = d0*t0  
d0*t0 + a2*x2 = d1*t1  
d1*t1 + a3*x3 = d2*t2  
… …  
dn-3*tn-3 + an-1*xn-1 = an 
 
我们从最后一个方程开始解，这里每一个方程都是二元线性丢番图方程，按照上面讲的方法 
从后往前求解，即可求出所有的 x，而后再根据题目的 flag 生成方法，将 x 中的数据代入
即 可得到答案：
