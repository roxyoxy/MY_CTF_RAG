## 二、第一层：Håstad 广播攻击（e=3）

**"宇宙广播"字面即题解**：同一明文 m 用 e=3 广播给三个模数（n0, n1, n2）。

前提检查：
- `gcd(n_i, n_j)` 两两互素（全 =1，排除共模/共因子路线）
- e=3 且有 3 个模数 → m³ < n0·n1·n2 成立，CRT 无溢出

```python
from sympy.ntheory.modular import crt
import gmpy2
x, _ = crt([n0, n1, n2], [c0, c1, c2])   # 中国剩余定理合并
m, exact = gmpy2.iroot(gmpy2.mpz(x), 3)  # 整数立方根
print(exact)   # True —— 数学自证攻击成立
```

得到 m = 42 字节**二进制乱码**（332 bit）。不是 flag——它是下一层的密文（观察：m 与 nw 同为 332 bit 且 m < nw，尺寸匹配绝非巧合）。

## 三、第二层：分解 nw（面壁者的锁）

nw = 100 位（332 bit）合数。本地三板斧全空手：

- `sympy.isprime(nw)` = False（确实是合数）
- Fermat 分解 20 万轮无命中（因子不平衡）
- 10 万内无小因子（Pollard rho 短跑无望）

**上 FactorDB**（`factordb.com`，CTF 分解第一站）——一发入魂，状态 FF（完全分解）：

```
nw = 6620414351<10> × 1316844704...89<91>
```

一个小因子（6620414351）+ 一个 91 位素数。332 bit 的 RSA 模数配上 34 bit 的小因子 = 典型的"可查库/可 ECM"设计，本地硬算不如查库快。

## 四、第三层：用 nw 的私钥解密 m

```python
from math import gcd
p = 6620414351
q = nw // p
phi = (p - 1) * (q - 1)

for e in [3, 65537]:          # e 未知 → 常见值试
    if gcd(e, phi) != 1: continue
    d = pow(e, -1, phi)
    plain = pow(m, d, nw)     # m = 广播攻击所得
    print(e, plain.to_bytes(29, 'big'))
```

- e=3：乱码（gcd=1 可逆但结果非文本）
- **e=65537：`npusec{gOOdBYe187J3X1}`** ✅

> 📸 **[截图占位 03]** 存 `图片/03_解密出flag.png`
> 内容：e=65537 那轮终端输出 `npusec{gOOdBYe187J3X1}`（含 e=3 乱码对照更佳）

完整链条：三路广播(e=3) → 密文 m → nw 私钥(e=65537) → flag。

## 六、知识点沉淀

1. **Håstad 广播攻击**：同一明文、小指数 e、≥e 个不同互素模数 → CRT 合并后开 e 次整数根。题目名"广播"即提示。`gmpy2.iroot` 返回的 exact 标志是攻击是否成立的自检信号。
2. **多层套娃识别**：解出的"乱码"位数与另一个给定模数同 bit 且小于它 → 它是那个模数下的密文，不是终点。
3. **FactorDB** 是 CTF 大数分解第一站（`factordb.com`，支持 URL 直接查 `?query=N`）；本地 Fermat/rho/小因子三连空手时立刻转在线库。带小因子（<40bit）的 RSA 模数基本是被收录/可 ECM 的设计。
4. **e 未给**：先试 3、再试 65537，用 gcd(e, φ)=1 与可逆性过滤；解密结果可打印率（printable ratio）是快速判据。
5. **题面情报学**：变量名后缀 w=wallfacer、题干"掩体纪元"、《三体》梗全程提示"罗辑的宇宙广播"——CTF 题面和变量名是免费情报。
